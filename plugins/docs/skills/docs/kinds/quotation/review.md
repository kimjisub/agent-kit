# quotation: 내용과 문체 검증

표현(금액 열 정렬, 합계 행 강조, 쪽 경계, 표지 렌더) 검증은 [a4 review.md](../../layouts/a4/review.md) 다. 문체의 베이스는 `brands/<brand>/voice.md` 다. 아래는 quotation 의 내용과 톤 항목이다.

## 수치 정확성

- [ ] 모든 행의 금액이 수량 x 단가와 맞다
- [ ] 합계 행이 각 항목 금액의 합과 일치한다
- [ ] 부가세 포함, 별도 여부가 합계에 일관되게 반영됐다
- [ ] 금액 숫자에 천 단위 구분자가 있고 단위(원, 천 원 등)가 헤더나 셀에 있다

## 항목 일관성

- [ ] 항목명, 단가, 수량이 수신처와 합의한 내용과 일치한다
- [ ] 합의되지 않은 항목이 견적표에 섞이지 않았다
- [ ] 같은 항목이 두 번 계상되지 않았다
- [ ] 견적표의 마지막 열이 금액이고 마지막 행이 합계다

## 필수 조건 명시

- [ ] 견적 유효기간이 있다(날짜 또는 "발행일로부터 N일")
- [ ] 부가세 처리 방침이 있다(포함 또는 별도)
- [ ] 결제 조건이 있다(선불, 후불, 분할, 기한)
- [ ] 견적 조건이 `blockquote` 조건 박스에 들어갔다

## 구조, 가독성

- [ ] 합계와 핵심 조건이 본문 첫 쪽 안에 모두 보인다
- [ ] 표지의 수신처, 대상, 유효기간이 본문과 일치한다
- [ ] 결정에 불필요한 항목이 없다(정보 최소주의)

## 톤

voice.md 를 더 건조하게 적용한다. 견적서는 설득이 아니라 사실 나열이다.

- [ ] 항목명이 형용사와 수식어 없이 사실로 쓰였다
- [ ] "훌륭한", "최고의", "뛰어난" 같은 마케팅 어조가 없다
- [ ] 조건 설명이 짧은 명사형이나 개조식이다("부가세 별도"는 맞고, "부가세는 별도로 청구될 예정입니다"는 고친다)
- [ ] 인사말과 서두 문장이 없다(견적표가 본문 전부여도 된다)
