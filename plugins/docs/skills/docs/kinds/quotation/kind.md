# quotation: 간단 견적서

서사 없이 **품목, 금액, 조건을 빠르게 전달**하는 가벼운 정식 견적서다(1\~3쪽).

## 쓰는 자리

- 이미 합의된 범위에 대해 금액을 제시할 때
- 단순 항목이나 용역 견적. 예: 외주 개발, 유지보수 계약, 컨설팅 용역, 장비 납품
- 제안 배경 설명 없이 견적표 중심으로 전달할 때

## 다른 종류와의 차이

| | proposal | quotation |
|---|---|---|
| 핵심 질문 | 왜, 어떻게 | 무엇을, 얼마에 |
| 분량 | 5\~20쪽 | 1\~3쪽 |
| 설득 구조 | 서사와 근거 | 표와 조건 |

범위가 아직 합의되지 않았으면 견적이 아니라 proposal 단계다.

## 이 폴더 구성

| 파일 | 역할 |
|---|---|
| `kind.md` | 이 문서. 정체성, 다른 종류와의 차이, 레이아웃 |
| [structure.md](structure.md) | 결과물 구성, 견적표와 조건의 열 구성, 정보 최소주의, 독자별 가이드, 표지 변수, 호출 예시 |

| [review.md](review.md) | 내용과 문체 검증 체크리스트 |

문체의 베이스는 `brands/<brand>/voice.md`, 표현(컴포넌트, 쪽, 표지)은 [a4 layout.md](../../layouts/a4/layout.md) 다. 이 폴더는 quotation 에서 달라지는 내용만 적는다.

## 레이아웃별 차이

a4 하나만 쓴다. 견적서는 발행, 보관, 결재에 붙는 문서라 쪽 단위 PDF 가 맞고, 한두 쪽 안에 합계와 조건이 다 보여야 해서 슬라이드나 화면 문서로 나눌 이유가 없다. 발표 자리에서 금액을 보여야 하면 proposal 을 deck 으로 뽑고 그 비용 절에서 이 견적서를 가리킨다.
