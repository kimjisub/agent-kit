# quotation: 내용 구조

## 결과물 구성

1. **표지**. 로고, 카테고리, 제목, 발신, 수신, 대상, 유효기간, 담당, 기밀 조항
2. **견적표**. 항목, 수량, 단가, 금액 표(`table.amounts`)
3. **견적 조건**. 유효기간, 부가세, 결제 조건, 비고(`blockquote` 또는 목록)

## 본문 작성 방식

표지는 scaffold 단계에서 환경 변수로 채워진다. 본문은 scaffold 된 html 의 본문 자리에 **AI 가 직접 HTML 로 작성**한다.

- 절 제목은 `h2` 로 시작한다. `h1` 은 새 쪽에서 시작하므로 짧은 견적서에서는 `h1` 을 쓰지 않는다.
- 견적표는 `table.amounts`, 견적 조건은 `blockquote` 나 목록으로 쓴다.
- 인라인 스타일을 쓰지 않는다. 컴포넌트와 태그 의미를 거친다.

## 견적표

`<table class="amounts">` 를 단다. 금액 열 우측 정렬과 합계 행 강조가 이 클래스로 켜진다.

| 번호 | 항목 | 수량 | 단가(원) | 금액(원) |
|---|---|---|---|---|
| 1 | 관리자 웹 화면 개발(12개 화면) | 1식 | 18,000,000 | 18,000,000 |
| 2 | API 서버 개발과 배포 | 1식 | 12,000,000 | 12,000,000 |
| **합계** | | | | **30,000,000** |

- 열 순서는 번호, 항목, 수량, 단가, **금액(마지막)** 이다. 열 수를 바꿔도 금액은 마지막 열에 둔다.
- 합계는 항상 마지막 행에 둔다. 소계 행을 넣어도 합계를 최하단에 둔다.
- 합계 행 글자는 `<strong>` 으로 감싼다.
- 금액 숫자에 천 단위 구분자를 쓰고, 단위(원, 천 원 등)를 헤더나 셀에 적는다.
- 수량에는 단위(건, 명, 개월, 식, M/M 등)를 붙인다.
- 항목명은 짧게 쓰고, 범위 상세는 비고 열이나 각주로 뺀다.

## 견적 조건

유효기간, 부가세, 결제 조건처럼 조건성 텍스트는 `blockquote` 에 넣어 조건 박스로 보인다. 짧은 명사형이나 개조식으로 쓴다.

```html
<blockquote>부가세 별도, 견적 유효기간 발행일로부터 30일, 결제는 착수 50% 와 검수 완료 50%</blockquote>
```

조건이 넷 이상이면 `blockquote` 안에 목록으로 편다.

## 정보 최소주의 원칙

- 독자가 결정에 필요한 항목만 남긴다. 설명이 많으면 견적서가 흐려진다.
- 합계와 핵심 조건은 **본문 첫 쪽에서 모두 보여야** 한다.
- 범위 상세는 비고 열이나 각주로 뺀다. 표 본문의 항목명은 짧게 쓴다.

## 독자별 작성 가이드

- **구매, 총무 담당**. 금액, 조건, 유효기간을 분명히 쓴다. 항목 설명은 한 줄로 줄인다.
- **실무 담당(발주 부서)**. 항목별 범위를 한 단계 더 구체화한다(각주나 비고 열).
- **의사결정자(승인용)**. 합계와 핵심 조건이 본문 첫 쪽에 다 보이게 하고, 세부는 뒤로 보낸다.

## 표지 변수

```bash
KIND=quotation [BRAND=<brand>] <변수...> bash scripts/build.sh scaffold <문서 폴더>
```

표지 메타 라벨은 [kind.md](kind.md) 의 `labels` 가 정한다. 변수와 라벨의 짝은 이렇다.

| 변수 | 표지 라벨 | 기본값 |
|---|---|---|
| `CATEGORY` | 카테고리 | 비우면 `견적서`. 범위를 좁히려면 `유지보수 견적서` |
| `DOC_TITLE` | 탭 제목 | 폴더 이름 |
| `DOC_HEADER` | 러닝 헤더 | `DOC_TITLE` |
| `COVER_TITLE` | 표지 대제목(HTML 가능, `<br>` 줄바꿈) | `DOC_HEADER` |
| `SUBTITLE` | 표지 부제목 | 없음 |
| `COVER_FROM` | 발신 | 브랜드 기본값 |
| `COVER_TO` | 수신(회사명) | 없음 |
| `COVER_TARGET` | 대상(프로젝트, 품목) | 없음 |
| `COVER_PERIOD` | 유효기간 | 없음 |
| `COVER_OWNER` | 담당 | 없음 |
| `COVER_CONFIDENTIAL` | 기밀 조항 문구 | 브랜드 기본값 |

값을 비운 표지 줄은 표지에서 사라진다.

## 호출 예시

```bash
# 1) 표지를 포함한 빈 번들 생성
DOC_TITLE="관리자 웹 개발 견적서" \
DOC_HEADER="관리자 웹 개발 견적서" \
COVER_TITLE="관리자 웹 개발<br>견적서" \
COVER_FROM="OO개발" \
COVER_TO="A사 운영팀" \
COVER_TARGET="관리자 웹과 API 서버 개발" \
COVER_PERIOD="2026-07-02까지" \
KIND=quotation bash <skill-dir>/scripts/build.sh scaffold "/path/to/견적서"

# 2) /path/to/견적서/견적서.html 의 본문 자리에 견적표 HTML 을 직접 쓴다

# 3) 완성된 html -> pdf
bash <skill-dir>/scripts/build.sh pdf "/path/to/견적서"
```

회사 양식이 필요하면 `BRAND=<id>` 를 붙인다(기본 `default`). 컴포넌트 마크업은 [a4 layout.md](../../layouts/a4/layout.md#tableamounts-금액-표) 에 있다.
