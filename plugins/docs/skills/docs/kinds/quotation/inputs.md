# quotation: 작성 전 선행 재료

견적서는 **합의된 정보를 정리하는 문서**다. 합의되지 않은 항목을 견적에 넣으면 혼선과 재작업이 생긴다. 아래 체크리스트를 모두 채운 뒤 작성한다.

## 범위 확정

- [ ] 견적 대상 서비스와 항목을 수신처와 명확히 합의했다
- [ ] 합의되지 않은 항목이 견적표에 섞이지 않았다(미합의 항목은 proposal 대상)
- [ ] 항목별 범위의 경계(포함, 제외 사항)가 분명하다

## 금액 데이터

- [ ] 모든 항목의 단가가 확정됐다
- [ ] 수량 단위가 분명하다(건, 명, 개월, 식, M/M 등)
- [ ] 합계 금액을 다시 계산해 검증했다
- [ ] 부가세 포함, 별도 여부를 정했다

## 조건 정보

- [ ] 견적 유효기간을 정했다(날짜 또는 "발행일로부터 N일")
- [ ] 결제 조건을 합의했다(선불, 후불, 분할, 기한)
- [ ] 기타 특약과 비고 사항이 있으면 정리했다

## 표지 정보

- [ ] 수신처(회사명, 담당자)가 정확하다
- [ ] 대상 프로젝트나 품목 이름이 확정됐다
- [ ] 발신 담당자 이름이 맞다

## 원칙

합의 안 된 범위는 견적에 넣지 않는다. 불확실한 항목은 견적표 밖에서 따로 논의하거나 proposal 단계에서 다룬다.
