# proposal: 내용과 문체 검증 체크리스트

표현(컴포넌트, 표, 쪽 경계, 표지 렌더) 검증은 고른 레이아웃의 `layouts/<layout>/review.md` 다(a4 는 [a4 review.md](../../layouts/a4/review.md)). 문체의 베이스는 `brands/<brand>/voice.md` 다. 아래는 proposal 의 내용과 톤 항목이다.

## 요약

- [ ] 첫 1\~2쪽 안에 제안 범위, 금액, 기간, 기대효과, 결정 요청이 있다
- [ ] 요약만 읽고도 "받을지 말지"를 판단할 수 있다
- [ ] "왜 지금, 왜 이 방식인가"의 논거가 주장이 아니라 사실로 2\~3개 있다
- [ ] 결론이 앞에, 근거가 뒤에 있다
- [ ] 1절 요약이 문서 맨 앞에 있고 `summary` 상자는 1절에 하나만 있다

## 설득 흐름

- [ ] 문제, 제안, 근거, 실행 계획, 비용과 일정, 다음 단계가 끊기지 않고 이어진다
- [ ] 제안이 2절에서 정의한 문제를 실제로 푼다(문제와 무관한 기능 자랑이 없다)
- [ ] 검토한 대안이 있으면 비교하고 이 안을 고른 이유를 적었다
- [ ] 받는 쪽이 이미 아는 내용을 가르치는 어조가 없다

## 근거

- [ ] 차별점과 기대효과가 형용사 없이 수치와 사실로 적혔다
- [ ] 수치마다 출처와 기준 시점이 있다. 추정은 추정이라고 적었다
- [ ] 검증할 수 있는 근거(사례, 실적, 레퍼런스)가 하나 이상 있다
- [ ] `metrics` 값에 단위가 있고, 추정 수치에는 `note` 로 근거가 붙었다

## 실행 계획과 책임 범위

- [ ] 실행 단계가 `phases` 나 단계 표로 한눈에 보인다
- [ ] 단계마다 업무, 산출물, 기간이 있다
- [ ] 단계마다 받는 쪽이 할 일이 있다
- [ ] 책임 범위 표가 있고, 제안하는 쪽과 받는 쪽의 담당이 나뉘어 있다
- [ ] 책임 범위 셀에 기호(체크, 대시) 대신 말이 적혔다
- [ ] 제외 범위가 구체적으로 나열됐다
- [ ] 받는 쪽 지연이 일정에 미치는 영향을 다뤘다

## 일정과 비용

- [ ] 일정 표가 있고, 마일스톤마다 시점과 산출물이 있다
- [ ] 받는 쪽 의사결정 버퍼가 일정에 들어 있다
- [ ] 비용의 계산 기준, 총액, 지급 조건이 적혔다(`pricing-placement` 결정대로)
- [ ] 금액에 천 단위 구분자, 통화 단위, VAT 포함 여부가 있다
- [ ] "별도 협의", "추후 결정"으로 비워 둔 곳이 없다. 미정이면 확정 조건을 적었다
- [ ] 요약의 금액과 기간이 본문의 수치와 같다

## 리스크

- [ ] 리스크가 현실적이고 각각 대응이 있다
- [ ] 불리한 사실을 숨기지 않았다

## 다음 단계

- [ ] `next` 상자가 문서 끝 다음 단계 절에 하나만 있다
- [ ] 결정 요청이 한두 개로 좁혀져 있고 회신 기한이 있다
- [ ] 결정 후 첫 일정이 있다

## 독자 적합성

- [ ] `target-audience` 결정에 맞춰 요약 길이와 본문 깊이를 조정했다
- [ ] `proposal-kind` 결정에 맞는 근거가 중심에 있다
- [ ] 약어와 전문 용어를 처음 쓸 때 풀었다
- [ ] 결정 공란(`@ASK`)이 남은 채 본문을 쓰지 않았다

## 표지 값

- [ ] `CATEGORY` 가 `PROPOSAL` 이나 `PROPOSAL / ...` 형식이다
- [ ] 기밀 조항이 `confidentiality` 결정대로 들어가거나 빠졌다
- [ ] 러닝 헤더(`DOC_HEADER`)가 문서 내용과 맞다
- [ ] 기밀 문구를 본문에서 반복하지 않았다

## 톤: 설득하되 사실이 설득하게

proposal 은 voice.md 기조 위에 설득의 자신감을 더한다. 자신감은 형용사가 아니라 수치와 사례에서 나온다.

- [ ] 격식 있는 어조다. 구어체와 마케팅 카피 톤이 섞이지 않았다
- [ ] 근거 없는 형용사("탁월한", "최고의", "혁신적인")가 없다
- [ ] 헤지 표현("\~할 것으로 예상됩니다")을 실제로 불확실한 곳에만 썼다
- [ ] 절마다 결론이 첫 문장에 있다
- [ ] 느낌표와 이모지가 없다
