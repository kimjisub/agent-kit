# brief: 외주 의뢰서

**계약을 맺은 외부 작업자가 무엇을, 어디까지, 어떤 방향으로 만들면 되는지를 한 번에 알게 하는 문서**다. 로고와 브랜드 디자인, 일러스트, 영상, 원고, 소규모 개발 의뢰가 여기 든다. 읽는 사람은 대등한 사업자이고, 이 문서를 받아 작업을 시작한다.

## 쓰는 자리

- 로고, 브랜드 컬러, 명함 같은 브랜드 디자인 의뢰
- 일러스트, 영상, 원고 외주
- 랜딩 페이지나 작은 기능 하나를 맡기는 개발 외주

## 다른 종류와의 차이

| | brief | proposal | spec |
|---|---|---|---|
| 쓰는 쪽 | 일을 맡기는 쪽 | 일을 따내려는 쪽 | 만드는 팀 |
| 읽는 쪽 | 계약한 외부 작업자 | 결정권자 | 구현하는 사람 |
| 목적 | 작업을 시작하게 한다 | 승인을 받는다 | 동작을 정확히 정한다 |
| 정본 | 계약서가 정본이고 이 문서는 그 풀이다 | 이 문서가 제안의 정본이다 | 이 문서가 정본이다 |
| 성공 기준 | 작업자가 질문 없이 방향을 잡고, 받은 결과물이 범위와 맞는다 | 결정이 난다 | 구현이 명세와 같다 |

고르는 기준은 이렇다. 계약이 끝났거나 곧 끝나고 상대가 작업을 시작해야 하면 brief, 아직 일을 따내는 중이면 proposal 이다.
