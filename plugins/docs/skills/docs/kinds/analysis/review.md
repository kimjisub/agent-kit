# analysis: 내용과 문체 검증 체크리스트

표현(컴포넌트, 표, 쪽 경계, 표지 렌더) 검증은 고른 레이아웃의 `layouts/<layout>/review.md` 다(a4 는 [a4 review.md](../../layouts/a4/review.md)). 문체의 베이스는 `brands/<brand>/voice.md` 다. 아래는 analysis 의 내용과 톤 항목이다.

## 핵심 요약

- [ ] 핵심 요약(`summary`)이 문서 첫머리에 하나만 있고, 독자가 거기만 읽어도 결론을 안다
- [ ] 요약이 본문과 일치한다. 요약에 나온 수치와 결론을 본문의 근거가 뒷받침한다
- [ ] 요약이 "검토가 필요하다"류의 유보만 있고 실제 결론이 빠져 있지 않다

## 방법, 출처

- [ ] 데이터를 어떻게 모으고 분석했는지 서술되어 있다(L2 이상 필수)
- [ ] 출처가 구체적이다(DB 이름, 기준일, URL, 인터뷰 대상 등)
- [ ] L3 독자 대상이면 쿼리, 도구, 재현 절차가 들어 있다

## 수치, 주장

- [ ] 모든 수치에 기준 시점이 있다
- [ ] 추정값은 "추정" 또는 "약 N"으로 표기했고, 실측값과 섞이지 않는다
- [ ] 주요 수치를 교차 검증했거나, 검증하지 못한 사유가 "한계" 절에 있다
- [ ] 지표 숫자에 천 단위 구분자가 있고, 값이나 라벨에 단위가 있다

## 발견 사항

- [ ] 발견 사항이 분석 목적에 답한다. 목적과 무관한 내용이 본문을 채우지 않는다
- [ ] 각 `finding` 이 구체적 근거(표, 수치)를 가리킨다
- [ ] `finding` 이 발견 사항 절에 모여 있고 절당 2\~3개 이내다
- [ ] 형용사와 막연한 서술 대신 숫자와 사실로 쓰였다

## 검증, 한계

- [ ] "검증, 한계" 절(또는 `note`)이 있고, 데이터 커버리지, 표본 편향, 이상치 처리가 적혀 있다
- [ ] `note` 가 설명하는 수치나 주장 바로 아래에 있다
- [ ] 불리하거나 불확실한 사실을 숨기지 않았다
- [ ] 주요 가정이 드러나 있고, 가정이 바뀌면 결론도 달라진다는 점이 보인다

## 깊이 일관성

- [ ] 고른 깊이 레벨(L1/L2/L3)이 독자와 맞는다
- [ ] 독자가 섞여 있으면 L1 요약이 첫 쪽에, L2/L3 상세가 부록에 있다
- [ ] 깊이에 맞지 않는 내용(L1 독자 문서에 재현 절차 상세 등)이 본문 중간에 끼어 있지 않다
- [ ] 부록이 있으면 본문에서 "부록 A 참조"처럼 명시적으로 가리킨다

## 결론, 다음 단계

- [ ] 결론이 발견 사항에서 도출된다. 근거 없이 결론만 있지 않다
- [ ] 다음 단계나 시사점이 있다면 담당, 기한, 대상이 드러날 만큼 구체적이다

## 표지 값

- [ ] 분석대상, 공유, 기간 값이 본문 내용과 맞다
- [ ] 기밀 조항이 내부 보고와 외부 공유 여부에 맞게 들어가거나 빠졌다

## 톤

voice.md 를 그대로 따른다. 아래는 확인용이다.

- [ ] 형용사, 느낌표, 이모지 없이 숫자와 사실로 썼다
- [ ] 추정에는 "추정", "약 N" 표기가 있다
- [ ] 한계와 불리한 사실을 숨기지 않고 드러냈다
- [ ] 결정 공란(`@ASK`)이 남은 채 본문을 쓰지 않았다
