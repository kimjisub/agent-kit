# analysis: 작성 전 입력 체크리스트

작성을 시작하기 전에 아래 항목이 준비됐는지 확인한다. 빠진 항목이 있으면 먼저 조사해 채운 뒤 작성한다.

## 결정 공란

- [ ] [structure.md](structure.md#데이터-깊이-가이드) 의 결정 공란(target-audience, depth-level)을 사용자와 모두 정했다

## 분석 범위 정의

- [ ] 분석 목적이 한 문장으로 정리되어 있다("무엇을 왜 알고 싶은가")
- [ ] 분석 대상(시장, 제품, 사용자 집단, 기간 등)이 명확히 정의되어 있다
- [ ] 독자가 누구인지 파악되어 있다. L1/L2/L3 깊이를 고르는 전제다

## 데이터, 출처

- [ ] 주요 수치의 원천 데이터가 확보되어 있다(DB 조회 결과, 인터뷰 기록, 공개 자료 등)
- [ ] 각 수치에 기준 시점이 있다
- [ ] 출처를 문서 안에 밝힐 수 있다(외부 공유 가능 여부 포함)
- [ ] 추정값과 실측값이 구분되어 있다

## 검증

- [ ] 핵심 수치를 한 번 이상 교차 검증했거나, 검증하지 못한 사유가 기록되어 있다
- [ ] 이상치, 결측, 오류를 식별했고 처리 방식을 정했다
- [ ] 분석 방법(쿼리, 기준, 도구)이 재현 가능한 형태로 메모되어 있다(L3 독자 대상이면 필수)

## 한계, 불확실성

- [ ] 데이터 커버리지의 한계(표본 편향, 비공개 모수 제외 등)를 파악했다
- [ ] 검증되지 않은 추정은 "추정"으로 표기할 준비가 되어 있다
- [ ] 결론에 영향을 줄 수 있는 주요 가정을 식별했다

## 표지, 메타

- [ ] `DOC_TITLE`, `COVER_TITLE`, `COVER_TARGET`, `COVER_TO`, `COVER_PERIOD` 값이 확정되어 있다
- [ ] 내부 보고인지 외부 공유인지 정했다(기밀 조항 `COVER_CONFIDENTIAL` 에 영향)
