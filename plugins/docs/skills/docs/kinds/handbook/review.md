# handbook: 내용과 문체 검증

표현 검증은 `layouts/<layout>/review.md` 입니다.

## 내용

- [ ] 0장만 읽고 이 문서가 무엇을 다루고 어떻게 읽는지 알 수 있다
- [ ] 모든 장에 "읽는 사람"과 결론이 담긴 `ch-lead` 가 있다(0장, 참고 장 제외)
- [ ] 대상별 장이 같은 절 순서를 따르고, 빠진 절은 의도한 것이다
- [ ] 진행 상황과 일정이 "지금" 장에 모여 있고 대상별 장에 흩어져 있지 않다
- [ ] 주소, 경로, 명령이 실제로 확인한 것이다
- [ ] 수치에 기준 시점이 있다
- [ ] 비밀 값(비밀번호, 토큰, 개인 키)이 없다. 값이 있는 곳만 적었다
- [ ] 같은 사실이 두 장에 다르게 적혀 있지 않다. 한 곳에 쓰고 다른 곳은 링크한다
- [ ] 이미 있는 문서를 옮겨 적지 않고 가리켰다
- [ ] 열린 위험과 정해지지 않은 것이 드러나 있다(`.risk`, `.tag.t-risk`, `.tag.t-open`)
- [ ] 마지막 장이 인계 직후 할 일과 인수 확인 기준으로 끝난다(인수인계서라면)
- [ ] 화면 캡처에 개인정보가 보이지 않는다

## 문체

- [ ] 본문은 `~입니다`체이고, 표 셀과 짧은 불릿만 명사형이나 `~한다`다
- [ ] 키보드로 칠 수 없는 문자가 없다(`grep -nP '[^\x00-\x7F\p{Hangul}]' <html>`, 코드와 인용 제외)
- [ ] 편지(0장)를 뺀 본문에 감탄과 인사가 없다
