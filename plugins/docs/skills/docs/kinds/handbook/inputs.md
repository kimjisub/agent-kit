# handbook: 쓰기 전에 모을 재료

handbook 은 사실의 양이 많은 문서라, 재료를 먼저 모으고 쓰는 편이 빠릅니다. 쓰면서 찾으면 같은 사실을 장마다 다르게 적게 됩니다.

## 공통

- [ ] 독자 목록과 각자 읽을 장(구조의 `@ASK(readers)`)
- [ ] 다룰 대상의 목록(제품, 서비스, 서버, 계정, 정기 업무). 저장소 목록, 서버 목록, 구독 목록에서 뽑습니다
- [ ] 이미 있는 문서의 위치(README, 위키, 설계 문서). handbook 은 그 문서를 옮겨 적지 않고 가리킵니다
- [ ] 용어 목록. 조직 안에서만 쓰는 말과 약어

## 대상별 재료

- [ ] 무엇이고 누가 쓰나(한 문장)
- [ ] 구성 요소와 위치(저장소 경로, 서버, 주소)
- [ ] 배포와 되돌리기 절차
- [ ] 기대는 외부 서비스와 계정, 그 값이 있는 곳(값 자체는 넣지 않습니다)
- [ ] 데이터와 백업, 복구해 본 적이 있는지
- [ ] 알려진 함정과 열려 있는 위험
- [ ] 지금 진행 중인 일과 잡힌 일정

## 사실 확인

- [ ] 주소, 경로, 명령은 실제로 열거나 돌려 보고 씁니다. 기억으로 쓴 경로는 한 번 확인합니다
- [ ] 수치(사용자 수, 비용, 건수)에는 기준 시점을 붙입니다
- [ ] 화면 캡처는 최신 화면으로 찍고 개인정보를 가립니다

## 인수인계서라면

- [ ] 최종 근무일과 그 뒤 연락 경로
- [ ] 역할 배분이 정해진 것과 정해지지 않은 것
- [ ] 인수 확인 기준(무엇을 직접 해 보면 인수가 끝났다고 보나)
