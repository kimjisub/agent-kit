# deck 표현 검증 체크리스트

공통 베이스로 [`brands/<brand>/design-principles.md` 의 검증 베이스](../../brands/default/design-principles.md#검증-베이스)와 [`brands/<brand>/voice.md`](../../brands/default/voice.md)를 먼저 적용한다(기본 `brands/default/`). 이 문서는 deck 고유 항목만 담는다. 내용 검증은 `kinds/<kind>/review.md` 다.

규칙의 근거와 스니펫은 [layout.md](layout.md) 에 있다.

---

## 1. 세로 공간: 넘침과 공백의 균형

**1920x1080 고정 캔버스라 자동 분할이 없다. 넘치면 잘리고, 적으면 하단이 빈다.** 가장 중요한 항목이다.

- [ ] PDF 로 굳힌 뒤 모든 슬라이드에서 내용이 캔버스 하단(1080px)을 넘어 잘리지 않는다
- [ ] **내용이 적은 슬라이드의 하단이 과하게 비지 않는다.** 본문을 `.slide-content`(필요하면 `.spread`, `.top`)로 감싸 세로 균형을 잡았다
- [ ] 빈 슬라이드를 그대로 두지 않았다(글자나 시각 요소를 키우거나 두 슬라이드를 합침)
- [ ] 불릿이 많은 슬라이드에서 마지막 항목이 footer 위에 여백을 두고 끝난다
- [ ] 불릿이나 표 행이 6개를 넘는 슬라이드가 없다(넘으면 나누거나 부록 슬라이드로 보냄)
- [ ] 이미지에 `max-height` 를 지정했다(`.product-image` 기본값 320px, 이미지 전용 슬라이드는 최대 560px 권장)
- [ ] `flex:1` 영역이 지정한 컨테이너 안에서만 늘어나고 슬라이드 밖으로 넘치지 않는다
- [ ] `.bottom-paragraph` 와 `.cta-bar` 를 `.slide-content` 밖에 뒀다(안에 두면 중앙 정렬이 풀린다)
- [ ] 긴 단어나 URL 이 줄바꿈 없이 캔버스를 가로로 벗어나지 않는다(`word-break: keep-all` 이나 수동 분리)

## 2. 슬라이드 번호, footer 일관성

- [ ] 표지를 뺀 모든 본문 슬라이드에 `.slide-footer` 가 있다
- [ ] `.slide-footer` 안에 `<span class="footer-left"></span>` 이 있다(비워 두면 CSS 가 로고를 넣는다)
- [ ] 슬라이드 번호(`.slide-number` 와 footer 우측 `<span>`)가 순서대로 늘고 오탈자가 없다
- [ ] 섹션 표지 footer 의 번호도 덱 전체 순서에 맞게 셌다
- [ ] 진행 표시 수단이 하나다. 스테퍼를 쓰면 `.slide-number` 에 섹션명을 겹쳐 적지 않는다

## 3. 정렬, 여백 일관성

- [ ] 모든 본문 슬라이드의 좌우 패딩이 100px 로 같다(`.slide-body` 기본값)
- [ ] `.slide-header` + `.slide-rule` 패턴이 모든 본문 슬라이드에 같게 쓰였다
- [ ] 같은 역할의 컴포넌트(KPI, 불릿, 타임라인 등)가 덱 전체에서 같은 클래스로 마크업됐다
- [ ] 인라인 스타일로 여백이나 크기를 준 곳이 이웃 슬라이드와 어긋나 보이지 않는다

## 4. 브랜드 색 절제

- [ ] `var(--brand-primary)`(주색)는 포인트 요소(`.slide-number`, `.period`, 강조 괘선 등)에만 쓰였다
- [ ] 주색이 긴 본문 텍스트나 넓은 배경에 쓰이지 않았다(섹션 표지 배경은 예외)
- [ ] 색을 hex 로 직접 적지 않고 `var(--brand-*)`, `var(--gray-*)`, 클래스를 거쳤다
- [ ] 섹션 표지 배경색이 덱 안에서 일정한 규칙(같은 섹션 = 같은 색)을 따른다

## 5. 이모지, 장식 금지

- [ ] 텍스트에 이모지가 없다(아이콘이 필요하면 인라인 SVG 나 `.sp-icon`)
- [ ] 느낌표 남발이나 광고 문구 톤이 없다
- [ ] 뜻 없는 장식 도형, 과한 그림자, 그라데이션 배경이 없다
- [ ] **`box-shadow` 가 없다.** Chrome PDF 인쇄가 둥근 요소의 그림자를 네모로 깐다(`grep -n box-shadow` 로 확인)
- [ ] **원문자(동그라미 숫자)가 없다.** 일반 숫자나 스타일 배지를 쓴다(`grep -nP '[\x{2460}-\x{24FF}\x{2776}-\x{2793}]'` 로 확인)
- [ ] 화살표와 특수 기호를 글자로 넣지 않고 인라인 SVG 로 넣었다
- [ ] 좁은 컨테이너의 한국어 문장에 `word-break: keep-all` 을 줘 단어가 중간에 끊기지 않는다
- [ ] 글자가 발표용 최소선(본문과 설명 17px, 캡션 15px) 이상이다(송부용 덱은 한 단계 작게 허용)
- [ ] KaTeX 수식을 썼다면 PDF 에서 `\( ... \)` 원문이 아니라 수식으로 렌더됐다(오프라인 빌드 주의)

## 6. 표지 슬라이드

- [ ] 첫 슬라이드가 `cover.html` 이 만든 `.cover` 다
- [ ] 표지의 브랜드 요소(로고, 카테고리 레이블, 제목, 부제, 메타)가 정확하거나, 비워 둔 자리가 사라져 있다
- [ ] 브랜드 이름과 로고가 없는 양식이면 표지 좌상단에 빈 로고 상자가 남지 않았다

## 7. 렌더 검증 (PDF 를 굳힌 뒤)

- [ ] `pdftoppm -png -r 55 <pdf> _render/s` 로 전 슬라이드를 이미지로 떠서 눈으로 확인했다(넘침, 잘림, 과한 공백, 깨진 글리프)
- [ ] 글자 크기를 일괄 조정했다면 밀도 높은 슬라이드(표, 장단점 비교, 다단 카드)를 전부 다시 확인했다

## 8. 공통 베이스 재확인

- [ ] 브랜드 색이 규칙대로 쓰였다(주색 남용, 보조색 침범 없음)
- [ ] 한 슬라이드의 강조 요소(`.metric`, 색 박스 등)가 둘 이내다
