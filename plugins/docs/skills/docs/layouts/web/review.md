# web: 표현 검증

먼저 `brands/<brand>/design-principles.md` 의 검증 베이스를 적용합니다. 그중 A4 흐름 문서에만 맞는 항목(measure 160mm, 타입 스케일 pt 값)은 이 레이아웃의 `style.css` 값으로 봅니다. 내용과 문체 검증은 `kinds/<kind>/review.md` 입니다.

## 구조

- [ ] 장 번호, 절 번호, 장별 목차를 손으로 적지 않았다(스크립트가 만든다)
- [ ] 장과 절의 `id` 가 영문 kebab-case 이고 문서 안에서 겹치지 않는다
- [ ] 문서 안 링크(`href="#..."`)가 모두 있는 id 를 가리킨다
- [ ] 사이드 목차에 모든 장과 절이 뜨고, 파트 머리가 파트가 바뀔 때만 뜬다

## 컴포넌트

- [ ] 같은 모양의 내용에 같은 컴포넌트를 썼다(서버 목록이 한 장에서는 카드, 다른 장에서는 표가 아니다)
- [ ] 두 문장 넘는 설명이 표 셀에 갇혀 있지 않다
- [ ] 그림마다 `alt` 와 캡션이 있고, 캡션이 그림 읽는 법을 말한다
- [ ] 강조 상자(`.risk`, `.warn`)가 한 절에 둘을 넘지 않는다

## 화면과 인쇄

- [ ] 화면: 스크롤하면 사이드 목차의 현재 장이 펼쳐지고 현재 절이 강조된다
- [ ] 화면: 폭 1000px 이하에서 사이드 목차가 사라지고 격자가 한 단으로 접힌다
- [ ] 인쇄: 표지가 한 쪽이고 장마다 새 쪽에서 시작한다
- [ ] 인쇄: 꼬리말에 문서 이름과 쪽 번호가 찍힌다
- [ ] 인쇄: 표 행, 상자, 그림이 쪽 경계에서 잘리지 않는다
- [ ] 웹폰트(Pretendard)가 로드됐다
