# a4 표현 검증 체크리스트

`brands/<brand>/design-principles.md` 의 검증 베이스를 먼저 적용한다(기본 [default](../../brands/default/design-principles.md#검증-베이스)). 아래는 a4 레이아웃에서 더 보는 표현 항목이다. 내용과 문체는 `kinds/<kind>/review.md` 가 본다. 컴포넌트 사용법은 [layout.md](layout.md#컴포넌트-카탈로그) 에 있다.

PDF 를 쪽 이미지로 뽑아 눈으로 본다(`pdftoppm -r 50 -png <pdf> <접두사>`). html 만 읽고 판정하지 않는다.

## 표지

- [ ] 카테고리, 제목, 부제가 kind.md 기본값이나 지정값대로 찍혔다
- [ ] 메타 다섯 줄의 라벨이 kind.md 의 `labels` 와 같고, 값이 라벨과 맞는 자리에 들어갔다
- [ ] 비운 표지 값의 줄과 상자가 빈칸으로 남지 않고 사라졌다
- [ ] 러닝 헤더(`DOC_HEADER`)가 둘째 쪽부터 찍히고 표지에는 없다
- [ ] 쪽 번호가 둘째 쪽부터 오른쪽 아래에 `n / 전체` 로 찍힌다
- [ ] 장식이 없다. 색 띠, 장식 선, 대문자로 벌린 꼬리표, 색 바탕 상자, 줄무늬 표, 제목 앞 막대를 문서 전용 스타일로 되살리지 않았다
- [ ] 절 머리말이 쪽 끝에 혼자 남지 않았고, 쪽을 넘는 표는 머리줄이 다음 쪽에 되풀이된다

## 컴포넌트

- [ ] `summary` 와 `next` 의 첫 자식이 `.label` 이다
- [ ] `finding`, `tip`, `warn`, `open` 의 첫 자식이 `.tag` 다
- [ ] `metric-value` 와 `metric-label` 이 `.metric` 안에만, `.metric` 이 `.metrics` 안에만 있다
- [ ] `metrics` 한 줄에 카드가 2\~5개이고, 넘으면 블록을 나눴다. 카드끼리 라벨 길이가 비슷하다
- [ ] `phases` 가 3\~5단계이고, 넘거나 설명이 길면 세로 단계 표로 바꿨다
- [ ] `step` 번호가 절마다 1부터 시작한다
- [ ] `note` 가 대상 표, 수치, 절차 바로 아래에 붙어 있다
- [ ] `endpoint` 의 메서드 클래스가 적힌 메서드와 맞다(`get`, `post`, `put`, `patch`, `delete`, `event`)
- [ ] 한 쪽의 강조 상자(`summary`, `next`, `finding`)가 합쳐 둘 이하다
- [ ] 한 쪽의 `tip` 과 `warn` 이 합쳐 셋 이하다
- [ ] 컴포넌트를 인라인 스타일로 흉내 낸 곳이 없다. 문서 전용 스타일은 `<style>` 끝에 클래스로 더했다

## 차트

- [ ] 차트가 있으면 [charts.md](charts.md#검증) 의 검증 항목을 통과했다
- [ ] 배경을 끈 인쇄(`page.pdf({ printBackground: false })` 나 브라우저 인쇄 미리보기)에서도 뜻을 가진 점, 막대, 칸이 남는다

## 표

- [ ] 필드 표에 `class="fields"` 가, 금액 표에 `class="amounts"` 가 붙어 있다
- [ ] 금액 표의 마지막 열이 금액이고 우측 정렬로 렌더됐다
- [ ] 금액 표의 마지막 행이 합계이고 강조로 렌더됐다. 합계가 아닌 행이 강조를 받지 않는다
- [ ] 합계 행 글자를 `<strong>` 으로 감쌌다
- [ ] 셀 병합이 의미 단위로만 쓰였다
- [ ] 열 너비와 셀 여백이 고르고, 한글 어절이 음절 중간에서 끊기지 않았다
- [ ] 일정은 간트 차트 대신 텍스트 타임라인 표다

## 코드와 이미지

- [ ] 예시 코드가 `<pre><code>` 안에 있고 들여쓰기가 맞다
- [ ] 코드 블록 안에도 키보드로 칠 수 없는 문자(곡선 따옴표, 화살표 기호)가 없다
- [ ] `->` 가 화살표 글리프로 바뀌지 않고 글자 그대로 찍혔다
- [ ] 이미지가 번들 `assets/` 를 상대 경로로 가리키고 렌더에 보인다

## 쪽 경계

- [ ] 표, 코드 블록, 상자, `metrics`, `phases`, `step` 이 쪽 경계에서 잘리지 않았다
- [ ] 한 쪽보다 긴 표와 코드 예시는 나눠 실었고, 나눈 표에도 헤더 행이 있다
- [ ] 제목이나 `endpoint` 줄이 쪽 끝에 홀로 남지 않았다
- [ ] 큰 덩어리가 밀려 앞 쪽 아래가 절반 넘게 빈 곳이 없다
- [ ] `h1` 이 새 쪽에서 시작한다. 짧은 문서는 `h1` 없이 `h2` 부터 썼다

## 줄 길이와 폰트

- [ ] 긴 산문 절은 `.prose` 로 감쌌고, 표와 불릿 위주 절은 전폭을 쓴다
- [ ] Pretendard 웹폰트로 렌더됐다(시스템 폰트로 떨어지지 않았다)
