# 기본 디자인 원칙 (brands/default)

모든 레이아웃이 상속하는 디자인 기준이고, 각 레이아웃 `review.md` 가 이어받는 베이스 체크입니다. 색과 폰트의 실제 값은 `brand.css`(CSS 변수)와 `brand.env`(@page hex)에 있고, 이 문서는 그 토큰을 어디에 쓰는지를 정합니다.

## 원칙

1. **정보 우선.** 장식보다 데이터입니다. 한 페이지가 전하는 정보의 밀도와 위계를 먼저 봅니다.
2. **색은 포인트로만.** 주색은 rule, 바, 라벨, 지표 숫자에만 씁니다.
3. **같은 의미는 같은 컴포넌트로.** 레이아웃 컴포넌트를 인라인 스타일로 대신하지 않습니다.
4. **흑백으로 찍어도 위계가 읽혀야 합니다.** 크기, 굵기, 괘선, 여백으로 위계를 만들고 색은 보탭니다.
5. **접근성.** 본문 10pt 이상(화면 문서는 16px), 충분한 명도 대비, 표 헤더와 본문의 구분.

## 톤

기본은 의사결정용입니다. 읽는 사람이 판단을 내려야 하는 문서(제안, 검토 요청, 내부 보고)는 차분한 무채색에 주색을 서너 군데만 쓰고, 큰 글씨와 면색 카드를 쓰지 않습니다. 무엇을 정해야 하는지가 장식보다 먼저 보여야 합니다. 성과 공유나 발표처럼 인상이 중요한 문서는 a4 에서 크기를 키우지 말고 `deck` 레이아웃으로 뽑습니다.

## 색

| 토큰 | 쓰는 곳 | 쓰지 않는 곳 |
|---|---|---|
| `--brand-primary` | 표지 밴드, h1 밑줄 rule, h2 왼쪽 바, 콜아웃 바와 라벨, 지표 숫자, 합계 행 | 제목과 강조 텍스트의 글자색, 표 헤더 채움, 넓은 배경 |
| `--brand-accent` | 표지 accent bar, 기밀 상자, 인용 바, 링크 밑줄 | 제목, 표 헤더 |
| `--brand-*-tint` | 요약, 합계, 콜아웃 상자의 옅은 배경 | 본문 전체 배경 |
| `--ink`, `--ink-soft`, `--line`, `--muted` | 본문과 제목 텍스트, 메타, 구분선 | |

- 제목과 볼드 텍스트는 `--ink` 입니다. 브랜드색으로 글자를 물들이면 페이지가 알록달록해집니다.
- 주색과 보조색을 한 요소에서 겹쳐 쓰지 않습니다.
- 의미 색(성공 초록, 위험 빨강)은 브랜드와 별개로 둡니다.

## 위계

- 제목은 h1 > h2 > h3 순서를 건너뛰지 않습니다.
- 인접 단계는 또렷이 벌립니다(h1 19, h2 14.5, h3 12, 본문 10pt).
- 한 페이지의 강조 상자는 둘까지입니다. 다 강조하면 아무것도 강조되지 않습니다.
- 표 헤더는 헤어라인 괘선과 작은 글씨이고 채움이 없습니다.
- 표는 라벨과 값, 항목과 수치를 대조할 때만 씁니다. 설명 문장이 길어지는 항목은 불릿으로 폅니다.

## 가독성

- 산문은 `--measure`(약 160mm) 상한을 둡니다. 표와 지표 카드는 전폭을 씁니다. a4 는 기본이 전폭이고, 산문이 긴 절만 `.prose` 로 상한을 켭니다.
- 본문 행간 1.55, 제목 1.2 입니다.
- 폰트는 Pretendard 하나입니다. 렌더에서 웹폰트가 실제로 로드됐는지 봅니다(시스템 폰트로 떨어지면 품질이 크게 떨어집니다).

## 금지

- 이모지. 아이콘이 필요하면 인라인 SVG 를 씁니다.
- 과장 캡션, 뜻 없는 장식 도형, 과한 그림자와 그라데이션.
- 토큰을 우회한 hex 하드코딩. `var(--brand-*)` 나 레이아웃 컴포넌트를 거칩니다.

## 검증 베이스

- [ ] 주색이 rule, 바, 라벨, 지표 숫자에만 쓰였다
- [ ] 제목과 볼드 텍스트가 잉크색이다
- [ ] 표 헤더가 채움 없는 헤어라인 괘선이다
- [ ] 산문이 긴 절에 measure 상한이 있다(a4 는 `.prose`)
- [ ] 긴 설명이 표 셀에 갇혀 있지 않다
- [ ] hex 하드코딩 없이 토큰과 클래스를 거쳤다
- [ ] 이모지와 과장 장식이 없다
- [ ] 제목 위계가 순서대로이고 단계 차이가 보인다
- [ ] 한 페이지 강조 요소가 둘 이하다
- [ ] 표지의 브랜드 요소(로고, 태그라인, 법인명, 기밀 문구)가 정확하거나, 비워 둔 자리가 사라져 있다
- [ ] 표와 상자가 페이지 경계에서 잘리지 않았다
- [ ] 키보드로 칠 수 없는 문자가 본문에 없다(`grep -nP '[^\x00-\x7F\p{Hangul}]'`, 코드와 인용 제외)
