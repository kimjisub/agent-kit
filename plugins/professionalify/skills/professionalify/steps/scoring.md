# 완성도 채점

**로드 시점: 검증이 끝난 뒤, 사용자가 발송할지 한 번 더 다듬을지 정하는 자리에서.** 각 축의 `measure.md`가 준 0~20 점수를 5차원 100점으로 모은다.

## 차원과 축의 대응

| 차원 (0~20) | 근거가 되는 축 | 감점 |
|---|---|---|
| AI 티 제거도 | 01 | |
| 구조 적합도 | 04 (슬라이드는 11, 화면은 13이 대신) | 03의 6유형 잔존 시 -3 |
| 톤 일관성 | 02 (화면은 12가 대신) | 14 S1 부재 시 -5, 03의 1, 2, 4유형 잔존 시 -5 |
| 디테일 정확성 | 02 디테일 채점표, 07, 08, 09, 10 중 켜진 것의 평균 | 03의 5, 7유형 잔존 시 -3, 05 미확인을 확인으로 쓴 것 -5 |
| 문서 목적과 완결성 | 06 (사업계획서는 15, 기술 문서는 16이 대신) | 05 근거 없는 주장 3건 이상 -5, 14 협의 요청 부재 -5 |

켜지지 않은 축은 감점하지 않는다. 한 차원에 축이 여럿이면 평균한다. 축 5는 독립 차원이 아니라 디테일과 완결성에 감점으로 들어간다. 축 3도 감점으로만.

## 등급

| 점수 | 등급 | 권고 |
|---|---|---|
| 90~100 | Excellent | 발송 준비 완료 |
| 75~89 | Good | 발송 가능, 미세 조정 권장 |
| 60~74 | Fair | 추가 다듬기 필요. 약점 차원의 축을 라이트~미디엄으로 재적용 |
| 45~59 | Needs Work | 미디엄 옵션 재적용 |
| 0~44 | Poor | 재설계 권장. 헤비 옵션 또는 문서 분리 |

## 출력 형식

```
| 차원 | 점수 | 근거 |
|---|---:|---|
| AI 티 제거도 | XX/20 | 문서 층 grep 합계, 문장 층 ID별 잔존, 변경률 |
| 구조 적합도 | XX/20 | 불릿+표 비율, 중복 횟수, 문장형 헤더 수 (또는 슬라이드 주장 비율, 화면 위계) |
| 톤 일관성 | XX/20 | 종결어미 혼용, 격조 판정, 감점 사유 |
| 디테일 정확성 | XX/20 | 약칭 정의, 기호, 표기, 표 단위, 차트 규칙, 다이어그램 라벨, 감점 사유 |
| 문서 목적과 완결성 | XX/20 | 단일 목적 여부, 행동 유도, 분량, PSST 항목, 문서 종류, 감점 사유 |
| 종합 | XX/100 | 등급, 권고 |
```

## 근거 작성

점수의 근거는 항상 구체 인용 또는 측정값이다.

| 약함 | 강함 |
|---|---|
| AI 티 잘 제거됨 | D-1 0회, C-11 3회 -> 0회, '본 PoC' 1회 잔존, 변경률 18% |
| 구조 깔끔 | 불릿+표 28%, 중복 0회, 문장형 헤더 0 |
| 톤 적절 | "~합니다"와 "~함" 혼용 0회, 인용문 구어체는 인용 |
| 디테일 OK | 약칭 정의 도입부, §, ★ 0회, 표 3개 전부 단위, 차트 이중 축 0 |
| 목적 명확 | 단일 목적, "2026-06-30까지 회신" 명시, 3쪽 |

## 75점 미만일 때

약점 차원을 짚고 다음 iteration을 한 줄로 권고한다.

- "구조 적합도 12/20: 불릿+표 55%. 축 4 미디엄 재적용."
- "디테일 정확성 9/20: 표 4개 중 3개 단위 없음, 그림 2 이중 축. 축 7과 8 라이트."
- "문서 목적 8/20: 견적과 기술 명세 혼재. 축 6 헤비(분리) 권장."

## 점수의 위치

점수는 참고 지표이지 자동 결정이 아니다. 95점이어도 사용자가 법인격 표기가 마음에 안 들면 그 차원만 다시 한다. 65점이어도 마감이 임박했으면 발송할 수 있다. 마지막 결정은 사용자가 한다.
