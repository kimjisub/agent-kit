# 축 15. 사업계획서: 측정

**로드 시점: 측정과 검증 단계에서.** 켜지는 조건과 왜는 `axis.md`, 고치는 법은 `improve.md`.

## 신호

| 신호 | 어떻게 보이나 | 심각도 |
|---|---|---|
| 문제(P) 없이 해법부터 | 첫 절이 제품 설명. 어떤 고통을 누가 겪는지 없음 | S1 |
| 문제에 근거 없음 | "많은 기업이 어려움을 겪는다"에 수치, 인터뷰, 사례 없음 | S1 |
| 해법(S)이 기능 나열 | 문제와 대응되지 않는 기능 목록 | S1 |
| 실현 가능성 증거 부재 | 프로토타입, PoC, 고객 검증, 기술 검증 중 하나도 없음 | S1 |
| 시장 규모 출처 없음 | TAM-SAM-SOM 숫자에 통계청, 협회, 공공 자료 인용 없음 | S1 |
| SOM 산식 없음 | 도달 가능 시장이 "TAM의 10%"처럼 근거 없이 | S2 |
| 성장 전략(S)에 자금 계획 없음 | 지원금을 어디에 얼마 쓰는지, 그 뒤 수익 모델이 없음 | S1 |
| 목표가 정성적 | "시장 선도", "고객 만족" 같은 측정 불가 목표 | S2 |
| 팀(T) 역량과 필요 역량 불일치 | 필요한 역량(영업, 하드웨어)이 팀에 없는데 채울 계획이 없음 | S1 |
| 심사 순서 역행 | 팀 소개가 맨 앞, 시장이 맨 뒤 | S2 |
| 양식 이탈 | 지정 양식 대신 자체 양식, 지정 분량 초과 | S1 (탈락 사유) |
| 첨부 누락 | 요구된 증빙(사업자등록, 특허, 계약서) 없음 | S1 (탈락 사유) |
| 자기 PR | "독보적", "혁신적" 반복 (축 1, 2와 겹침) | S2 |
| 견인(traction) 없음 | 매출, 계약, 사용자, LOI 중 하나도 없음 (투자용) | S1 |
| 요청 없음 | 얼마를 무엇에 쓰겠다는 요청이 없음 (투자용) | S1 |

## 측정 방법

PSST 골격 체크리스트를 채운다.

```
| 항목 | 있는가 | 위치 (절) | 근거 유형 (축 5의 5등급) | 심사 항목 대응 |
| P 문제 인식: 배경, 필요성, 고객 페인포인트 | | | | |
| S 실현 가능성: 해법, 차별점, 검증 결과 | | | | |
| S 성장 전략: 시장(TAM-SAM-SOM), 진입, 자금, 목표 | | | | |
| T 팀: 대표와 팀원 역량, 필요 역량과 확보 계획 | | | | |
```

심사 배점표가 공개돼 있으면 그 표와 대조한다. 항목마다 어느 절이 답하는지 적는다.

```bash
# 출처 표기
grep -cE "통계청|KOSIS|협회|백서|보고서|출처|Source|https?://" <file>
# 시장 규모 용어
grep -nE "TAM|SAM|SOM|시장 규모|억 원|억 달러" <file>
# 정성 목표
grep -nE "선도|만족|최고|혁신적|독보적" <file>
# 자금 사용 계획
grep -nE "지원금|자금|예산|사용 계획|집행" <file>
# 검증 증거
grep -nE "PoC|프로토타입|시제품|LOI|계약|매출|사용자 [0-9]+|인터뷰" <file>
# 분량
wc -w <file>; grep -c '^#' <file>
```

양식 준수는 공고문과 대조한다. 양식 파일명, 분량 상한, 글자 크기, 첨부 목록.

## 채점 (0~20)

steps/scoring.md의 "문서 목적과 완결성"과 "디테일 정확성"에 나눠 들어간다. 양식 이탈이나 첨부 누락이 있으면 10점을 넘지 못한다.

| 점수 | 기준 |
|---:|---|
| 20 | PSST 네 항목 전부, 심사 순서 일치, 시장 규모 출처, 자금 계획, 팀 역량 대응, 양식과 첨부 준수 |
| 15 | 항목 하나 약함 (SOM 산식 등) |
| 10 | 항목 하나 부재 또는 출처 없음 |
| 5 | 해법부터 시작. 검증 증거 없음 |
| 0 | 양식 이탈 또는 첨부 누락 |

## 오탐 주의

- 공고문이 PSST가 아닌 자체 항목을 요구하면 그 항목이 우선이다. PSST는 대응표로만 쓴다.
- 투자자 덱은 PSST 이름을 안 쓰지만 순서(문제, 해법, 시장, 견인, 팀, 요청)가 같다. 이름이 아니라 순서를 본다.
- 초기 단계(예비창업)는 검증 증거가 인터뷰나 설문일 수 있다. PoC를 요구하지 않는다.
- 시장 규모가 작은 틈새는 SOM이 TAM에 가까울 수 있다. 비율이 아니라 산식이 있는지 본다.
