# 축 5. 논증과 정직성: 측정

**로드 시점: 측정과 검증 단계에서.** 켜지는 조건과 왜는 `axis.md`, 고치는 법은 `improve.md`.

## 신호

| 신호 | 어떻게 보이나 | 심각도 |
|---|---|---|
| 근거 없는 주장 | "~가 명백하다", "시장이 원한다", "고객이 선호한다"에 출처, 수치, 관측이 없음 | S1 |
| 확신과 근거의 불일치 | 추정치 하나에 "확실히", 실측 열 건에 "~일 수 있다" | S1 |
| 확신 표현 자의성 | "아마", "대체로", "상당히"가 문서 안에서 서로 다른 확률로 쓰임 | S2 |
| 반론 부재 | 대안이 있는 결정인데 다른 선택지와 그것을 안 고른 이유가 없음 | S1 |
| 한계 부재 | 추정, 표본, 미확인 항목이 있는데 한계 절이나 "확인 안 됨" 표기가 없음 | S1 |
| 상대 수치만 | "2배", "50% 증가"만 있고 기저값이 없음 | S1 |
| 참조 집단 부재 | "10명 중 3명"인데 어떤 10명인지 없음. 비율의 분모가 없음 | S2 |
| 거짓 정밀도 | 추정치에 유효숫자 4자리("시장 규모 22.37억 달러") | S2 |
| 출처 등급 미표기 | 실측, 1차 자료, 2차 자료, 리서치 업체 추정, 전언이 구분 없이 같은 무게로 | S2 |
| 인과와 상관 혼동 | "A 뒤에 B가 늘었다"를 "A가 B를 늘렸다"로 | S1 |
| 선택적 증거 | 지지하는 사례만 있고 반대 사례를 찾았는지 없음 | S2 |
| 미확인을 확인으로 | "LS XGT 드라이버가 없다"처럼 못 찾은 것을 없다고 씀 | S1 |
| 인용의 기능을 놓침 | 말을 정확히 옮겼는데 화자가 그 말로 무엇을 하려 했는지(포문, 반박, 전환, 자조)가 앞뒤에 없음. 읽는 사람이 다른 뜻으로 읽는다 | S1 |
| 현상만 있고 지금의 처리가 없음 | 운영 문서가 "링크가 주석으로 꺼져 있다", "IP 가 바뀌면 막힌다", "외부 데이터가 오래됐을 수 있다"처럼 결함만 적고 왜 그렇게 됐는지, 지금은 무엇으로 대신하는지, 그 상태가 실제로 그런지를 적지 않음. 읽는 사람은 "그럼 지금 어떻게 하고 있지"를 다시 조사한다 | S1 |
| 남의 주장을 필자 목소리로 | 강연, 인터뷰, 보고서를 옮기면서 화자 표기 없이 단정으로 씀. 발송자가 보증한 사실로 읽힘 | S1 |

## 측정 방법

문서의 주장을 표로 뽑는다. 이것이 이 축의 핵심 도구다.

```
| # | 주장 (한 문장) | 근거 | 근거 유형 | 확신 표현 | 일치 여부 |
```

근거 유형은 다섯 등급이다.
1. 실측 (직접 돌려서 본 것. grep 결과, 로그, DB 조회)
2. 1차 자료 (원문 문서, 공식 가격표, 코드)
3. 2차 자료 (기사, 리뷰, 요약)
4. 추정 (리서치 업체 시장 규모, 본인 계산)
5. 전언과 추측 (들었다, 그럴 것이다)

확신 표현과 근거 유형이 맞는지 본다. 1~2등급 근거에는 단정이 맞고, 4~5등급에는 유보가 맞다.

```bash
# 확신 부사와 형용사
grep -ncE "명백히|분명히|확실히|당연히|의심의 여지|반드시" <file>
# 유보 표현
grep -ncE "일 수 있|로 보|추정|가정|가능성|아마|대체로|확인하지 못|미확인|확인 필요|예상" <file>
# 부정 단정 (없다, 않는다로 끝나는 주장)
grep -noE "[가-힣 ]{6,}(없습니다|않습니다|없다|않는다)\." <file>
# 상대 수치 (기저값 확인 필요)
grep -nE "[0-9]+배|[0-9]+% (증가|감소|상승|하락)" <file>
# 출처 표기
grep -c "출처\|Source\|https://\|실측\|확인" <file>
# 한계와 반론 절 존재
grep -nE "^#+ .*(한계|제약|반론|위험|열린 질문|확인 필요|미확인)" <file>
# 거짓 정밀도 (추정치에 소수점 둘 이상)
grep -nE "추정.*[0-9]+\.[0-9]{2,}|[0-9]+\.[0-9]{2,}.*추정" <file>
```

인용마다 그 말의 기능을 한 줄로 적어 본다. "이 말로 화자가 무엇을 했는가"에 답이 안 나오면 원본(전사본, 녹취, 원문)에서 그 대목의 앞뒤를 더 읽는다. 발언 앞뒤 1분은 요약을 쓰기 전에 읽는다.

남의 말을 옮긴 문서(강연 정리, 인터뷰, 회의 기록, 리서치 요약)는 문단마다 주어가 누구인지 본다. 화자가 사라진 문장은 발송자의 주장이 된다.

```bash
# 화자 표기 없이 단정으로 끝나는 문장 (남의 말을 옮긴 문서에서)
grep -cE "(했습니다|합니다|입니다)\." <file>
grep -cE "라고 (했|말했|봤|소개했)|고 합니다|는 진단|의 생각" <file>   # 화자 표기
```

눈으로 보는 것:
- 대안이 있는 결정마다 "왜 다른 것을 안 골랐나"가 있는가
- 못 찾은 것과 없는 것이 구분돼 있는가 ("확인하지 못했다" vs "없다")
- 비율마다 분모가 보이는가

## 채점 (0~20)

steps/scoring.md의 "디테일 정확성"과 "문서 목적과 완결성"에 나눠 들어간다. 이 축 자체 점수는 다음과 같다.

| 점수 | 기준 |
|---:|---|
| 20 | 모든 주장에 근거 유형 표기, 확신과 근거 일치, 대안과 한계 절 있음, 상대 수치에 기저값 |
| 15 | 불일치 1~2건 또는 한계 절이 약함 |
| 10 | 근거 없는 주장 3건 이상 또는 반론 부재 |
| 5 | 확신 표현이 근거와 반대. 미확인을 확인으로 씀 |
| 0 | 주장만 있고 근거가 없음 |

근거는 주장 표의 행 번호로 적는다. "주장 3, 7, 9에 근거 없음. 주장 12는 추정에 단정".

## 오탐 주의

- "~하지 않습니다"가 설계 결정("클러스터를 세우지 않습니다", "대규모 트래픽은 설계하지 않습니다")이면 주장이 아니라 결정이다. 근거를 요구하지 않는다. 사실 주장("경쟁사는 이 기능이 없습니다")만 근거를 본다. 2026-09-18 실측에서 방향성 문서의 부정 단정 8건 중 6건이 결정이었다.
- 유보 표현 grep은 어미가 아니라 어근으로 잡는다. "~로 보인다"는 "~로 보이며", "~로 봅니다"를 놓친다. 넓힌 패턴이 0을 내면 정말 없는 것이 아니라 패턴이 좁은 것부터 의심한다.

- 회의 발언 인용("공동창업자: ~라고 했다")은 주장이 아니라 기록이다. 근거를 요구하지 않는다.
- 결정 문서의 "우리는 A로 간다"는 근거가 아니라 선언일 수 있다. 근거는 그 앞 절에 있으면 된다.
- 내부 문서에서 "확인 필요"로 표기된 것은 정직한 미확인이라 S1이 아니다. 표기 없이 단정한 것만.
- 산업 관행("Sparkplug B가 표준이다")은 출처 없이 써도 되는 상식 범위가 있다. 독자가 그 분야 사람이면 통한다.
