## 측정 방법

**흑백 테스트.** 스크린샷을 흑백으로 바꾼다. 위계가 남으면 크기, 간격, 굵기로 만든 것이고, 사라지면 색에 기댄 것이다.

```bash
# 스크린샷 흑백 변환 (ImageMagick)
magick screenshot.png -colorspace Gray screenshot-gray.png
```

**스케일 이탈.** CSS에서 간격과 크기 값을 뽑아 분포를 본다.

```bash
# 간격 값 분포
grep -rhoE "(margin|padding|gap)[^:]*:\s*[0-9.]+(px|rem)" src | grep -oE "[0-9.]+(px|rem)" | sort | uniq -c | sort -rn | head -20
# 글자 크기 분포
grep -rhoE "font-size:\s*[0-9.]+(px|rem)" src | grep -oE "[0-9.]+(px|rem)" | sort | uniq -c | sort -rn
# 색 값 수 (팔레트가 있으면 적어야 함)
grep -rhoE "#[0-9a-fA-F]{6}" src | sort -u | wc -l
# Tailwind 프로젝트: 임의 값과 글자 크기 클래스 분포
grep -rhoE '\-\[[0-9]+px\]' src | sort | uniq -c | sort -rn | head
grep -rhoE 'text-(xs|sm|base|lg|xl|[2-4]xl)' src | sort | uniq -c | sort -rn
# 테두리 수
grep -rc "border:" src | awk -F: '{s+=$2} END{print s}'
```

Tailwind면 클래스 이름으로 같은 것을 센다(`p-[13px]` 같은 임의 값이 이탈).

**그룹핑.** 라벨과 그 입력 칸 사이 간격 < 입력 칸끼리 간격 < 절끼리 간격인지 잰다.

**주 행동.** 화면에서 주 행동 버튼을 가리고 사용자가 무엇을 하러 왔는지 묻는다. 버튼 스타일이 셋(primary, secondary, ghost) 이하인지.

**색 대비.** 텍스트와 배경의 대비를 잰다. WCAG AA는 본문 4.5:1, 큰 글자 3:1.

```bash
# 축 8의 팔레트 검증기가 대비도 본다
node <dataviz 스킬 경로>/scripts/validate_palette.js "<텍스트색,배경색>" --mode light
```

**대시보드.** 1440x900에서 스크롤 없이 다 보이는가. 가장 중요한 지표가 왼쪽 위인가.

**반응형.** 375px, 768px, 1440px에서 스크린샷. 겹침과 잘림. 폭마다 기능 목록(탭, 메뉴, 단축키)을 하나씩 눌러 닿는지 본다. 보이는지가 아니라 닿는지다.

터미널 화면은 tmux로 크기별 세션을 띄워 같은 키를 보내고 캡처한다. 150x44, 100x30, 80x24, 60x20이면 나란히 배치, 탭 줄 축약, 한 열 배치가 모두 걸린다. 마우스는 SGR 시퀀스(`\e[<0;열;행M`)를 그대로 보내 클릭을 재현한다. 한글은 두 칸이라 열을 셀 때 틀리기 쉽다.

```bash
for s in 150x44 100x30 80x24 60x20; do tmux new-session -d -s ui${s%x*} -x ${s%x*} -y ${s#*x} "<앱 실행>"; done
tmux send-keys -t ui60 Right; tmux capture-pane -pt ui60
```

## 오탐 주의

- Tailwind 프로젝트에서 `text-sm`이 압도적이고 `text-base`가 거의 없으면(2026-09-18 실측: 333 대 6) 14px이 사실상 본문 크기다. 스케일 이탈이 아니라 기본값이 옮겨진 것이니 본문 크기 판정을 14px 기준으로 한다. 문제는 그것과 별개로 임의 값(`-[17px]`)이 몇 종인가다.
- 인라인 px 값 여섯 종(20, 10, 40, 12, 30, 16)과 Tailwind 클래스가 섞여 있으면 두 시스템이 공존하는 것이고, 어느 쪽으로 몰지가 처방이다. 값의 종류 수만 세지 않는다.

- 데이터 밀도가 높은 전문가용 화면(트레이딩, 관제)은 여백 기준을 완화한다. 다만 위계는 있어야 한다.
- 브랜드 색이 위계의 일부일 수 있다. 흑백 테스트에서 "약간 약해지는" 것은 괜찮고 "사라지는" 것만 문제.
- 표준 아이콘(닫기 X, 검색 돋보기, 설정 톱니)은 라벨 없이 된다.
- 임의 값 하나(`p-[13px]`)는 이탈이 아니다. 열 개 이상이 시스템 부재의 신호.
