# 축 11. 슬라이드: 측정

**로드 시점: 측정과 검증 단계에서.** 켜지는 조건과 왜는 `axis.md`, 고치는 법은 `improve.md`.

| 신호 | 어떻게 보이나 | 심각도 |
|---|---|---|
| 주제 제목 | "시장 현황", "기술 아키텍처", "Q3 실적". 무엇을 봐야 하는지 없음 | S1 |
| 불릿 본문 | 불릿 4개 이상이 본문의 전부 | S1 |
| 여러 주장 | 한 장에 "그리고", "또한"으로 이어지는 주장 둘 이상 | S1 |

## 측정 방법

장마다 세 질문이다.
1. 제목만 읽고 이 장의 주장을 말할 수 있는가
2. 본문의 그림이 그 주장의 증거인가 (없으면 무엇을 넣을 수 있는가)
3. 발표자가 이 장 앞에서 슬라이드를 안 보고 말할 수 있는가

전체로 세 질문이다.
1. 첫 세 장 안에 결론이 있는가
2. 장수가 발표 시간(분) 이하인가
3. 마지막 장이 행동 유도(결정 요청, 다음 단계)인가

파일이 마크다운(marp, reveal)이나 HTML이면 센다.

```bash
# 장수
grep -c '^---$' <file>
# 불릿이 4개 이상인 장
awk '/^---$/{if(b>=4) print "장 "n": 불릿 "b; n++; b=0; next} /^\s*[-*] /{b++} END{if(b>=4) print "장 "n": 불릿 "b}' <file>
# 제목이 문장(주장)인가: 마침표나 동사 어미로 끝나는 H1/H2
grep -nE '^#{1,2} .*(다|됐다|줄었다|늘었다|이다|없다|있다)\.?$' <file> | wc -l
grep -c '^#{1,2} ' <file>
# 글자 수가 많은 장
awk '/^---$/{if(c>120) print "장 "n": "c"자"; n++; c=0; next} {c+=length($0)} END{if(c>120) print "장 "n": "c"자"}' <file>
```

PPTX와 Keynote는 `pptx` 스킬로 텍스트를 뽑아 같은 것을 센다.

## 채점 (0~20)

steps/scoring.md의 "구조 적합도"에 들어간다.

| 점수 | 기준 |
|---:|---|
| 20 | 모든 장 제목이 주장, 본문이 증거, 결론이 앞, 마지막이 행동 유도 |
| 15 | 주제 제목 1~2장 |
| 10 | 절반이 불릿 본문 |
| 5 | 대본이 슬라이드에. 결론이 끝 |
| 0 | 문서를 잘라 붙인 것 |

## 오탐 주의

- 목차, 구분 장, 질의응답 장은 주장이 없는 것이 정상이다. 세지 않는다.
- 부록 슬라이드(참고 표, 데이터)는 발표하지 않는 장이라 불릿과 표가 있어도 된다.
- 문서형 슬라이드(읽히는 덱)는 글자 수 기준을 완화하고 축 4를 같이 쓴다.
- 워크숍이나 강의 슬라이드는 한 장에 연습 문제 목록이 있을 수 있다.
