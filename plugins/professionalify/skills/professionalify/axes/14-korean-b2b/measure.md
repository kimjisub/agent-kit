# 축 14. 한국 B2B와 공공 양식: 측정

**로드 시점: 측정과 검증 단계에서.** 켜지는 조건과 왜는 `axis.md`, 고치는 법은 `improve.md`.

## 신호 (있어야 할 것의 부재)

| 항목 | 있어야 할 모습 | 없을 때 심각도 |
|---|---|---|
| 표지 + 기밀 조항 | 표지 하단에 기밀 유지, 저작권 문구 | S2 |
| 위계 기호 | 대분류 로마숫자, 중분류 아라비아, 항목 □, 세부 ○, 부연 - | S3 (마크다운이면 H1~H3로 대체 가능) |
| 개조식 종결 | 본문이 "~함 / ~임" 명사형. "~합니다"와 섞이지 않음 | S1 |
| 책임 분담 | "A는 ~ 전담, B는 ~ 담당 (~ 제외)" 문장. 괄호 안 제외 항목 | S1 |
| 약칭 정의 | 도입부에 정식 법인격 + "이하 고객사 / 개발사" | S1 |
| Phase 0 미확정 표기 | "현 시점에서는 확정된 개발 명세가 아닌 검토 대상 요소임" + 항목 목록 | S1 |
| 추가 비용 발생 기준 | 6~7가지 사유와 처리 방식 표 | S1 |
| 시나리오별 예산 | 자금 소스별 A, B, C안, 각각 총 예산 / 제안가 / 범위 | S2 (자금 미확정일 때 S1) |
| 직접비와 간접비 분리 | 예비비, PM 간접비, 보험료, 기술료, 행정비가 견적표에 행으로 | S2 |
| 표 구성 | 견적표 3~4열, 시나리오 요약 4열, 타임라인 5열. "비고"는 진짜 컨텍스트만 | S3 |
| 분기 단위 타임라인 | Q1, Q2로 발주처 단계와 개발사 Phase 병행 | S3 |
| 협의 요청 사항 | 문서 끝에 "감사합니다" 대신 예산 시나리오 확정, 계약서 초안 교환, 착수일 협의 | S1 |
| 자기 PR 절제 | "당사의 풍부한 경험", "최고의 기술력" 없음. 사실 진술만 | S2 |

## 측정 방법

```bash
# 종결어미
echo "합니다: $(grep -c '합니다' <file>)  함/임: $(grep -cE '(함|임)\.?$' <file>)"

# 있어야 할 문구
grep -c "기밀\|저작권" <file>
grep -c "전담\|담당함\|제외)" <file>
grep -c "이하 \"" <file>
grep -c "Phase 0\|검토 대상\|확정된 개발 명세가 아닌" <file>
grep -c "추가 비용\|별도 견적\|변경 계약\|별도 협의" <file>
grep -cE "A안|B안|C안|시나리오" <file>
grep -c "예비비\|간접비\|보험료\|기술료\|행정" <file>
grep -cE "Q[1-4]" <file>
tail -15 <file> | grep -c "협의 요청\|회신\|확정"

# 없어야 할 문구
grep -c "풍부한 경험\|최고의 기술력\|차별화된 솔루션\|독보적" <file>
```

## 채점

이 축은 steps/scoring.md의 별도 차원이 아니다. 측정 결과가 톤 일관성(종결어미, 자기 PR)과 디테일 정확성(약칭, 간접비, 표기)과 문서 목적, 완결성(협의 요청, 시나리오)에 나눠 들어간다. 한국 B2B 문서에서 S1 항목이 하나 빠지면 해당 차원에서 5점을 뺀다.

## 오탐 주의

- 내부 문서, 메일, 슬랙 공지는 이 축의 대상이 아니다. 개조식 종결을 요구하지 않는다.
- 위계 기호 □, ○는 마크다운에서 H2/H3와 불릿으로 옮겨도 된다. 기호 자체가 필수는 아니다.
- 1천만원 미만 단순 견적에는 간접비 분리와 시나리오 분기가 과하다.
- 상대가 준 RFP 양식이 있으면 그 양식이 우선이다.
