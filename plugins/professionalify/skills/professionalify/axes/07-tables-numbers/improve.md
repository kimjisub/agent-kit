# 축 7. 표와 수치: 개선

**로드 시점: 개선 단계에서, 합의된 범위 안에서.** 무엇을 잴지는 `measure.md`, 실제 전후 모양은 `examples.md`.

## 원칙

표는 값을 찾아 읽는 도구다. 독자가 찾을 값이 한 번에 보이고, 비교할 값이 같은 열에 위아래로 놓이고, 단위와 기준선이 셀 밖에서 한 번에 보이게 만든다. 데이터와 경쟁하는 것(굵은 선, 음영, 장식 열)은 뺀다.

## 처방

**조합은 표로 다 적는다.** 요구가 두 차원의 곱(형태 x 색, 플랫폼 x 크기)이면 행과 열로 놓아 모든 칸을 채운다. 칸마다 파일명이나 값을 적으면 빠진 것이 바로 보인다. 공통 조건(파일 형식, 해상도)은 표 아래 한 줄로.

**섞인 참조 열은 지운다.** 열 하나에 장 링크와 사실과 빈칸이 섞여 있으면 열을 지운다. 링크는 목차와 본문 참조가 이미 하므로 버리고, 다른 곳에 없는 사실만 옆 열의 문장 끝으로 옮긴다. 지우기 전에 그 사실이 문서 다른 곳에 있는지 grep 으로 본다.

전: `이름 / 자리 / 이 문서에서`. 칸이 "14장 3절", "4장", 빈칸, "유료 계정과 폰트가 이 사람 명의다"로 섞였다.
후: `이름 / 자리`. 폰트 명의는 계정 장에 이미 있어 버렸고, 유료 계정 명의만 자리 칸 끝으로 옮겼다.

**방향.** 시계열은 열이 시간(가로로 흐름), 항목이 행. 순위와 목록은 행이 항목(세로로 내려감). 비교는 비교 대상이 열, 비교 항목이 행.

**정렬.** 숫자는 오른쪽 정렬(`---:`), 문자는 왼쪽. 같은 열은 같은 유효숫자와 같은 단위.

**단위.** 열 머리에 한 번 (`금액 (원)`, `CPU (코어)`). 셀마다 반복하지 않는다. 열이 여러 단위를 섞으면 열을 나눈다.

**유효숫자.** 추정치 두 자리, 실측치는 측정 정밀도. 한 열 안에서 통일.

**기준선.** 값 옆에 비교 대상을 둔다. 전기 대비, 목표, 평균, 상한 중 이 표의 독자가 비교할 것 하나.

| 전 | 후 |
|---|---|
| 노드 / CPU 사용 | 노드 / CPU 사용 / 용량 / 사용률 |
| k8s-worker-03 / 1286m | k8s-worker-03 / 1286m / 16코어 / 8% |

**컬럼 줄이기.** 결정에 안 쓰이는 열을 뺀다. "비고"가 동어반복이면 지우고, 진짜 컨텍스트면 표 아래 단락으로.

| 전 (4열) | 후 (2열 + 단락) |
|---|---|
| No / 항목 / 금액 / 비고("공급사, 구조 확인, 접근 경로 판단 등") | 항목 / 금액. 표 아래: "현장 조사는 계근 프로그램 공급사와 DB 구조 확인, 네트워크 접근 경로 판단을 포함합니다." |

**합계.** 금액 표는 합계 행. VAT는 합계 아래 한 줄 (`공급가 합계 10,000,000원, VAT 포함 11,000,000원`).

**정렬 기준.** 행 순서를 하나로 정한다. 크기순(큰 것부터), 시간순, 또는 독자가 아는 순서(현장 순, 절 순). 입력 순은 안 된다.

**규칙선과 여백.** 마크다운에서는 선택지가 적다. 가로 규칙선은 머리 행 아래 하나. 그룹을 나누려면 빈 행 대신 표를 둘로 가른다. HTML/PDF면 세로선 없이 가로선만 옅게, 행 높이는 글자의 두 배, 열 사이 여백으로 구분.

**셀 안 문단.** 세 문장 이상이면 표에서 꺼내 단락으로. 표에는 한 구절 요약만 남기고 "아래 설명 참조".

**숫자에 맥락.** 비율 옆에 분모("92% (n=1,709)"), 평균 옆에 분산이나 범위("평균 43ms, 최대 210ms"), 단일 값 옆에 측정 시점("2026-09-17 13:40 KST, 1회").

**표를 안 쓰는 선택.** 값이 셋 이하면 문장이 낫다. "worker-03이 1286m, worker-04가 1531m이고 나머지 셋은 200m 이하입니다."

**따라 읽는 문서는 목록으로.** 읽는 사람이 값을 찾지 않고 항목을 하나씩 따라가는 문서(시나리오, 런북, 판정 체크리스트, 질문과 답)는 표를 쓰지 않는다. 항목마다 한 줄, 이름을 앞에 굵게, 부가 정보는 괄호로 뒤에 붙인다.

- 전: `| R44 | 회사 특정 | 딥다이브가 동명 회사를 가르고 이 회사로 특정했다 | 딥다이브 |`
- 후: `- **R44 회사 특정** — 딥다이브가 동명 회사를 가르고 이 회사로 특정했다 (세는 곳: 딥다이브)`

## 흔한 실수

- 정렬을 맞추려고 숫자를 문자열로 만든다("1,200 ").
- 기준선을 붙이려고 열을 늘려 표가 6열이 된다. 기준선 하나만.
- 합계 행을 넣고 항목 행과 같은 굵기로 두어 안 보인다. 합계는 볼드 또는 구분선.
- 비교표를 만들면서 비교 대상마다 열을 주고 항목이 행이 아니라 셀 안 불릿으로 들어간다.
- 컬럼을 빼면서 그 정보를 버린다. 단락으로 옮긴다.

## 검증

- 표마다 단위, 정렬, 기준선, 합계를 다시 본다.
- `grep -nE '^\| *(No\.?|비고|장점|특징|기대효과|근거) *\|'`가 0이거나 남은 것이 진짜 컨텍스트인지 본다.
- 셀 길이 80자 초과가 0인지 본다.
