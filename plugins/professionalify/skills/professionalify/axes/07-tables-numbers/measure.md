# 축 7. 표와 수치: 측정

**로드 시점: 측정과 검증 단계에서.** 켜지는 조건과 왜는 `axis.md`, 고치는 법은 `improve.md`.

## 신호

| 신호 | 어떻게 보이나 | 심각도 |
|---|---|---|
| 방향 어긋남 | 시계열이 세로(행이 월), 순위가 가로 | S2 |
| 숫자 정렬 | 숫자 열이 왼쪽 정렬이거나 소수점이 안 맞음 | S2 |
| 단위 부재 | 열 머리에도 셀에도 단위가 없음. "3.3"이 코어인지 GB인지 | S1 |
| 유효숫자 제각각 | 한 열에 "1,234.56"과 "1,200"과 "약 1천" | S2 |
| 컬럼 양 늘리기 | "비고", "장점", "기대효과", "근거" 열이 비어 있거나 동어반복 | S2 |
| 섞인 참조 열 | "이 문서에서", "관련" 같은 열에 장 링크와 사실 문장이 섞여 있고 칸 일부가 비어 있음. 무엇을 담는 열인지 열 제목으로 정해지지 않음 | S2 |
| 비교 기준 부재 | 값만 있고 전기, 목표, 평균, 상한 같은 기준선이 없음 | S1 |
| 굵은 규칙선 | 모든 셀에 진한 테두리. 데이터보다 선이 먼저 보임 | S3 |
| 행이 빽빽함 | 행 높이가 글자 높이. 옆 행으로 눈이 샘 | S3 |
| 셀 안 문단 | 한 셀에 세 문장 이상. 표가 아니라 단락을 격자에 넣은 것 | S2 |
| 합계 부재 | 금액 표에 합계 행이 없음 | S1 (견적) |
| 정렬 기준 없음 | 행 순서가 입력 순. 크기순, 시간순, 이름순 중 하나가 아님 | S2 |
| 숫자만 있고 맥락 없음 | "성공률 92%"에 표본 수가 없음 | S1 |
| 따라 읽는 문서의 표 | 위에서 아래로 읽으며 따르는 문서(시나리오, 런북, 체크리스트)의 규칙과 판정 항목이 표에 들어 있다. 항목 하나가 칸마다 한 구절씩 쪼개져 한 문장으로 읽히지 않는다 | S2 |
| 예시가 요구를 다 덮지 않음 | 요구는 "형태 넷마다 컬러, 검정, 흰색"인데 예시 표에는 일부 조합만 있음. 빠진 조합이 필요한지 모호해짐 | S1 |

## 측정 방법

표마다 아래를 본다.

```bash
# 표 수와 열 수 분포
grep -c '^|---' <file>
grep '^|---' <file> | awk -F'|' '{print NF-2}' | sort | uniq -c
# 오른쪽 정렬 지정 여부 (---: 가 있는가)
grep -c '^|.*---:' <file>
# 비고, 장점, 기대효과 열
grep -nE '^\| *(No\.?|비고|장점|특징|기대효과|근거) *\|' <file>
# 단위 없는 숫자 열 후보 (머리 행에 단위 괄호가 없는 것)
grep -nE '^\|.*[0-9].*\|' <file> | head -3
# 셀 안 긴 문장
awk -F'|' '/^\|/ { for(i=2;i<NF;i++) if (length($i) > 80) print NR": 긴 셀 "length($i)"자" }' <file>
# 합계 행
grep -nE '^\| *(합계|총계|계|Total)' <file>
```

눈으로 보는 것:
- 이 표에서 독자가 찾을 값이 무엇인가. 그 값이 한 번에 보이는가.
- 두 값을 비교하려면 눈이 어디서 어디로 가는가. 같은 열 안에서 위아래로 가면 맞고, 대각선이면 방향이 틀린 것.
- 컬럼을 하나 빼면 결정이 바뀌는가. 안 바뀌면 그 컬럼은 양 늘리기.

## 채점 (0~20)

steps/scoring.md의 "디테일 정확성"에 들어간다.

| 점수 | 기준 |
|---:|---|
| 20 | 모든 표에 단위, 정렬, 기준선, 합계(해당 시). 양 늘리기 열 0 |
| 15 | 1~2개 표에 사소한 문제 (정렬, 규칙선) |
| 10 | 단위 부재 또는 기준선 부재가 있음 |
| 5 | 표 절반 이상이 양 늘리기 열이나 셀 안 문단 |
| 0 | 표가 읽히지 않음 |

근거는 표 번호와 항목으로 적는다. "표 3 단위 없음, 표 5 비고 열 동어반복".

## 오탐 주의

- 체크리스트와 책임 매트릭스는 셀이 문장이어도 된다. 값을 찾는 표가 아니라 대응을 보는 표다.
- 비교표(제품 A vs B)는 셀이 길어도 된다. 다만 한 셀 세 문장을 넘으면 단락으로.
- 마크다운은 소수점 정렬이 안 된다. 오른쪽 정렬(`---:`)까지가 한계이고 그 이상은 요구하지 않는다.
- 이름 표(용어 대응)처럼 숫자가 없는 표는 정렬과 단위 항목을 끈다.
