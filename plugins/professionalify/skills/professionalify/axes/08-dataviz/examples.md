# 축 8. 데이터 시각화: 사례

**로드 시점: 개선 중 처방의 실제 모양이 필요할 때.** 규칙은 `improve.md`가 정본이고 여기는 사례만.

## 우리 사례

### 차트가 아니라 표가 답이었던 것 (2026-09-17, 클러스터 실측)

노드 5개의 CPU 사용률을 막대 차트로 그리려다 표로 갔다. 독자(공동창업자)가 찾을 값은 "어느 노드가 몇 %인가"와 "합계"였고, 값을 정확히 읽는 일이라 표가 맞다. 형태 판정의 첫 질문이 "차트인가"다.

### 값 하나는 숫자로 (같은 보고)

"클러스터 전체 CPU 4.5%"를 게이지나 도넛으로 그리지 않고 문장 첫 줄에 숫자로 썼다. 옆에 기준("72 vCPU 중 3.3코어")을 붙였다. 숫자 타일의 원칙과 같다.

### 파드 수 분포 (같은 보고)

17개 네임스페이스의 파드 수를 차트로 그리면 계열 17개다. 상위 5개(iot-qa 32, iot-prod 23, kube-system 18, svc-b-qa 15, svc-b-prod 15)만 문장으로 쓰고 "나머지 12개 네임스페이스는 합쳐서 49개"로 접었다. 9번째부터 "기타"의 원칙이다.

### 실측 시계열이 있었다면 (가정)

InfluxDB의 센서 포인트가 2026-07-23에 끊긴 것을 보이려면 선 차트 하나에 x축은 2026-06부터 2026-09까지 자르지 않은 구간, y축은 일별 포인트 수, 7/23에 세로 기준선과 직접 라벨 "consumer 크래시". 제목은 "센서 수집이 7월 23일 이후 0건"이지 "일별 센서 포인트 수"가 아니다.

### 자산 추이 열 계열을 한 축에 (2026-09-21, 개인 재무 화면)

폐기한 시트가 아홉 열을 한 그래프에 그렸던 대로, 입출금·투자·저축·보증금·대출·연금·포인트·코인·가수금과 합계 열 개를 한 y축에 아홉 색으로 겹쳤다. 보증금과 대출이 같은 달에 크게 반대로 뛰면서 축 범위가 커졌고, 나머지 여덟 선은 0 근처의 띠로 눌렸다. 범례가 열 개, 색은 아홉에서 순환. 사용자: "그래프가 개못생겼는데 적절한 그래프 표기법 식별해서 진행해봐".

고친 것. 합계 선 하나를 크게 위에, 항목마다 자기 축의 작은 패널(3열 격자)로. 잉크는 한 색, 범례 없음, 패널 머리에 이름과 마지막 값, 선 끝에 값을 직접 적음. 작은 패널은 눈금을 최소·0·최대 셋만. 같은 화면의 월별 막대에는 12개월 평균 점선을 기준선으로 넣고 연도 경계를 x축에 표시했다.

### 글로 쓴 수치가 남은 show 페이지 (2026-10-22)

사용자가 "여전히 텍스트가 많아" 라고 했다. 공용 공간의 show 페이지 18장을 재 보니 여섯 장에 문장 안의 수치 나열이 있었다. 로그 집계 페이지의 "91건, 8건, 10건, 9건" 이 한 문장이고, 화면 비교 페이지는 "450줄, 622줄, 1,242줄, 857줄" 을 한 문단에 이었다. 전자는 크기순 막대 하나와 결론 한 줄, 후자는 파일마다 줄 수 막대가 받는다. show 는 이 신호를 렌더러 검사(`✗ text:`)와 추세, 전후 값 태그로 넣었다.

## 모범 원본

- Tufte, The Visual Display of Quantitative Information의 Minard 나폴레옹 행군 도판. 여섯 변수를 잉크 낭비 없이.
- `dataviz` 스킬의 `references/anti-patterns.md`. 이중 축, 무지개, 순환 색, 0 아닌 막대 등 실패 목록과 대안.
- Financial Times Visual Vocabulary. "데이터의 일"별 형태 선택표의 원형.

## 반례

- 매출과 건수를 이중 축에 넣고 "상관이 보인다"고 한 것. 축 범위를 조정하면 어떤 관계든 만들어진다.
- 12개월 추세를 파이 12조각으로 그린 것. 시간은 파이에 없다.
- 계열 색을 파랑, 주황, 초록, 빨강으로 쓴 것. 빨강과 초록은 상태색이고 색약에게 같은 색이다.
- 검증기 없이 "충분히 다르다"고 한 팔레트. OKLab Delta E 6 미만이 두 쌍 있었다.
