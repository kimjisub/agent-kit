# 축 1. AI 슬롭: 측정

**로드 시점: 측정과 검증 단계에서.** 켜지는 조건과 왜는 `axis.md`, 고치는 법은 `improve.md`.

### 문서 층

| 신호 | 어떻게 보이나 | 심각도 |
|---|---|---|
| 친절 설명 | "받는 쪽이 ~할 수 있도록", "직관적입니다", "이해를 돕기 위해", "참고로", "보시다시피", "쉽게 말하면" | S2 |
| 자기 PR 반복 | "사전 검증", "차별화", "풍부한 경험", "독보적"이 3회 이상. "이 문서의 제안입니다", "이 제품의 성패입니다" 같은 자기 지시 | S1 |
| 인공 균형 | 모든 sub-section 같은 깊이, 모든 표 같은 컬럼 수, 모든 단락 비슷한 길이, 모든 문단이 `**용어.** 설명` 틀, 항목이 늘 셋("근거는 셋입니다") | S1 |
| 메타 표현과 클로징 | "다음과 같이 정리됩니다", "정리하면", 섹션마다 "결론적으로", "감사합니다"로 끝남, 문단 끝 경구("이것이 ~의 핵심이다") | S1 |
| 발음 불가 기호 | `§`, `★`, `→` 본문 산문 안 | S2 |
| 공간 은유 | 추상적인 대상에 "자리", "길", "곳"을 붙여 장소처럼 씀. "개인정보가 놓이는 자리", "알림이 사람에게 닿는 길", "실패해도 알림이 안 오는 자리", "사고가 나는 자리", "문서의 자리", "이 층이 맡을 자리", "값을 받는 곳", "비어 있는 곳". 같은 계열로 구조물과 손작업 비유도 센다: 관문(기준), 입구(접속, 요청), 창구(연락처), 앞단과 뒷단(초반과 후반 단계, 앞에), 갈래(종류, 워크플로우), 뿌리(기반), 닿다(연결, 오다), 얹다(적용), 깎다(개선), 살아 있다(실행 중), 문턱(기준값), 흔들림(편차), 묵다(오래된 값), 몰아 재다(세션을 띄워 시험하다). 설명문과 이력서에서는 세우다(만들다, 구축하다, 정하다), 짜다(설계하다, 만들다), 다듬다(최적화하다), 묶다(낮추다, 검증하다), 쌓다(관리하다), 갈아 끼우다(바꾸다), 그쪽에 걸다(그렇게 하다), 손을 대다(다시 개발하다), 뽑다(정리하다), 접다(중단하다), 사람이 붙다(사람이 처리하다)가 같은 계열이다. 하드웨어 문서에서는 띠(영역), 끌고 다니다(길게 긋다), 입구(바로 아래), 살아 있다(전원 유지)가 같은 계열이다. 읽는 사람이 실제 대상(저장 위치, 경로, 작업, 역할, 폴더)을 되짚어야 한다. 헤더와 장 도입부에 몰린다 | S2 |
| 흐린 "받다" | 주어나 받는 대상이 흐린 "받다". "인계 때 따로 받습니다"(누가 누구에게 어떻게), "Caddy 가 받는다", "트래픽을 받는다", "새 요구는 AX 쪽에서 받습니다", "판정을 더 받는다". 읽는 사람이 실제 동작(전달, 처리, 접속, 수집, 내려받기)을 되짚어야 한다. 이어받다, 넘겨받다, 내려받다와 돈, 메일, 인증 코드처럼 실제로 받는 것은 오탐 | S2 |
| 과장 | "0", "100%", "완전", "절대", "전혀" | S1 (법적 책임) |
| 체크마크와 이모지 | 헤더마다 ✓, 본문에 ✅ 🔥 💡 | S1 |
| 영어 격조 단어 | leverage, utilize, facilitate, comprehensive, robust, seamless, streamline, holistic, in order to | S2 |
| 영어 반복 구조 | "It is important to note that", "Furthermore" 단락 시작, "In conclusion" 매번, "By leveraging X, we can Y" | S2 |

## 측정 방법

먼저 Do-NOT을 제외한다. 고유명사, 제품명, 수치, 날짜, 발화자가 있는 직접 인용, 법 조문, 수학, 통계 표기, 업계 표준 영어 약어(API, LLM, MCP)는 세지 않는다. 그다음 문장별 내용 앵커(주장을 구성하는 핵심 명사, 개념어)를 목록화해 둔다. 개선 뒤 이 앵커가 남았는지 확인하는 데 쓴다.

```bash
# 문서 층
grep -c "본 PoC\|본 안\|본 제안\|이 문서의 제안\|성패입니다" <file>    # 자기 PR, 자기 지시
grep -c "§\|★\|✓\|✅\|🔥\|💡" <file>                                 # 기호, 이모지
grep -c "할 수 있습니다\|다음과 같습니다\|아래와 같습니다\|참고로\|보시다시피" <file>   # 친절, 메타
grep -c "이것이\|바로 이것" <file>                                    # 경구 후보
grep -o '\*\*[^*]*\*\*' <file> | wc -l                                # 볼드 수
grep -cE "셋입니다\.|넷입니다\.|세 가지" <file>                       # 항목 수 선언
grep -cE "운영 영향 0|100%|완전 독립|절대 안전" <file>                  # 과장

# 문장 층 (quick-rules ID)
grep -noE "[0-9]+[가-힣]{1,3}의 [가-힣]" <file>                         # 수량 + 관형격 의
grep -nE "(놓이는|놓일|닿는|들어갈|나는|맡을|하는) (자리|길|곳)|[가-힣]+의 자리|자리입니다|길입니다" <file>   # 공간 은유. 포지션, 자릿수, "그 자리에서"(즉시)는 오탐
grep -nE "(받는|드는|비어 있는|바뀌는) 곳|간 길|관문|입구|창구|앞단|뒷단|갈래|뿌리|닿[는을]|얹어|깎[는고]|살아 있|문턱|흔들|묵[었은다]|몰아 [재잴]|띠 |끌고 다니" <file>   # 구조물, 손작업 비유. "막힌다", "죽은 코드"는 개발 용어라 오탐
grep -nE "세[우웠워운]|짜[고서]|짰|짭니|다듬|묶었|쌓습|갈아 끼|쪽에 걸|손을 대|원칙을 뽑|접을지|사람이 붙" <file>   # 손작업 동사. 랙에 서버를 세우다, 잠금을 걸다, 기록을 쌓아 두다, 묶음(번들)처럼 실제 동작이면 오탐
grep -nE "(^|[^어겨려급정달])받[는아았고을습]" <file>   # 흐린 "받다". 이어받다, 넘겨받다, 내려받다, 돈과 메일은 오탐
grep -c "통해\|통하여" <file>                                          # A-2
grep -c "되어진\|지게 된" <file>                                        # A-8
grep -c "결론적으로\|요약하면\|정리하자면\|이를 통해\|그러므로" <file>       # D-1
grep -cE "혁신적|획기적|압도적|전례 없는" <file>                         # D-4
grep -cE "(고|며|지만|면서|아서|어서), " <file>                         # C-11 (개선 뒤 늘면 실패)
grep -cE "^(또한|따라서|즉|나아가|아울러|게다가|더욱이)" <file>            # H-1
grep -cE "이 아니라|것이 아니라|인가, " <file>                          # C-8 대구
grep -cE "하는 이유다|핵심은|필요한 것은|중요한 것은|결국" <file>           # D-8, D-9, D-10
grep -c "-" <file>                                                     # J-3
```

문장 층은 개선 뒤 변경률도 잰다. 레벤슈타인 거리를 원문 길이로 나눈 값이 5~30%면 정상, 30% 초과는 과윤문, 5% 미만은 S1 잔존을 다시 본다.

## 채점 (0~20)

문장 층과 문서 층을 합쳐 매긴다. S1 잔존이 하나라도 있으면 15점을 넘지 못하고, 변경률이 30%를 넘으면 10점을 넘지 못한다.

| 점수 | 기준 |
|---:|---|
| 20 | 문서 층 grep 합계 0~1회, 문장 층 S1 0건, S2 2건 이하, 변경률 10~25% |
| 15 | 문서 층 2~3회 또는 S2 3~4건 |
| 10 | 문서 층 4~6회 또는 S1 1~2건 또는 변경률 30% 초과 |
| 5 | 문서 층 7~10회 또는 S1 3건 이상 |
| 0 | 문서 층 11회 이상 또는 변경률 50% 초과 (내용 훼손 의심) |

근거는 ID와 빈도로 적는다. "D-1 4회, C-11 6회, '본 PoC' 5회, 변경률 미측정".

## 오탐 주의

- C-11 grep `(고|며|지만|면서|아서|어서), `는 "광고,", "그리고,", "학교," 같은 명사와 접속사도 잡는다. 2026-09-18 실측: 방향성 문서에서 63건이 걸렸고 표본 20건 중 6건이 오탐이었다. 수치는 상대 비교(개선 전후)에만 쓰고 절대값으로 채점하지 않는다.

- "~에 대해", "~를 통해", 문두 접속사, "~고 있다"는 사람도 쓴다. 고립 사용은 잡지 않는다.
- 대구 "A가 아니라 B"는 사람 필자도 다용한다(532편 중 31편). 2회 이상 연쇄일 때만.
- E의 "같은 종결어미 4문장 이상"은 한국어 정중체 산출물에서 거의 항상 걸린다. 문장 끝 네 글자를 비교하면 `습니다.`가 전부 같아서다. 2026-09-18 실측: 정중체 메일 177문장에서 4연속 구간이 넷 나왔고 모두 자연스러운 서술이었다. 이 신호는 문장 길이 균일(표준편차)과 함께 볼 때만 유효하고, 정중체 문서에서는 5연속 이상만 본다.
- 원문에 이미 있던 대시, 구어 종결("~인데요", "~거든요")은 사람 글의 증거다.
- 서법(당위, 추측)은 슬롭이 아니다. 강도가 아니라 표지의 반복만 본다.
- 볼드가 목차, 제목급에 있는 것은 정상이다. 본문 문단 첫머리에 반복될 때가 신호다.
