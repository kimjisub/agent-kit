# feedback-reply

Draft a reply, in your own first person, to feedback, objections or review comments from several people, answering every point. Each point gets one of four dispositions: accept fully, already covered (point to where), reframe a category mix-up, or keep it with layered reasons and a concrete list of concessions. Every claim is checked against the actual code or document before it is written. Korean only.

Skill docs are in Korean.

```
/plugin install feedback-reply --marketplace kimjisub/agent-kit
```

Installed as a plugin it runs as `/feedback-reply:feedback-reply`. Other agents can take the skill folder alone: `npx skills add kimjisub/agent-kit --skill feedback-reply`.
